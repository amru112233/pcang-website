# P&Cang Website — Konsep Kewirausahaan

Website satu halaman (single-page) untuk konsep bisnis P&Cang, agensi social media dan digital marketing yang berfokus pada industri konstruksi.

## Cara membuka
1. Unduh dan ekstrak file ZIP.
2. Buka folder `pcang-website`.
3. Klik dua kali `index.html`, atau buka file tersebut melalui browser (Chrome, Edge, Firefox).

Website memakai HTML, CSS, dan JavaScript biasa; tidak memerlukan instalasi, server, atau koneksi internet untuk menampilkan desain.

## Catatan sebelum dipublikasikan
- Formulir saat ini adalah demo front-end. Saat dikirim, formulir mengunduh ringkasan ke file `.txt`; data belum dikirim ke email atau server.
- Informasi harga, nomor WhatsApp, email bisnis, dan tautan media sosial belum ditambahkan karena belum tersedia pada materi kelompok.
- Bagian “Contoh konsep karya” merupakan ilustrasi konsep, bukan portofolio klien yang sudah dikerjakan.
- Periksa kembali nama merek, logo final, informasi layanan, dan klaim sebelum website dipakai sebagai kanal bisnis sungguhan.

## Struktur
- `index.html` — seluruh tampilan, gaya, dan interaksi website.
